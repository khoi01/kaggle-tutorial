## ✅ 1.2 Create Label Studio Project with `"stingless_bee"` Label

This step sets up the labeling environment to produce bounding box annotations in **YOLO format**.

### 📦 Requirements

* Docker + docker-compose (✅ you already have)
* Label Studio running at `http://localhost:8080` or similar
* A folder of raw images to upload (e.g., `v1/raw/`)

---

### 🧭 Step-by-Step: Create Project in Label Studio

#### 🖥️ 1. Open Label Studio

Go to `http://localhost:8080` in your browser.

#### ➕ 2. Click “Create Project”

* Name: `Stingless Bee Detection`
* Description (optional): `Label stingless bees in entrance and inside hive images.`

#### 🏷️ 3. Choose Labeling Interface → **Object Detection (Bounding Box)**

Click **“Use Template”** > **“Bounding Boxes”**

#### ✏️ 4. Customize Label Class

Click “Edit Labels” and enter:

```xml
<View>
  <Image name="image" value="$image" zoom="true"/>
  <RectangleLabels name="label" toName="image">
    <Label value="stingless_bee" background="yellow"/>
  </RectangleLabels>
</View>
```

✅ This creates 1 label class: `"stingless_bee"`.

---

### 📂 5. Upload Your Images

* Click **“Import Tasks”**
* Upload all images from `v1/raw/` or drag-and-drop them into the interface.
* They will appear in the task list ready to annotate.

> 💡 **Tip**: You can use the Docker volume to mount your local folder into Label Studio if you prefer not to upload manually.

---

### 📤 6. Label Images

* Start labeling each image by drawing bounding boxes around each visible stingless bee.
* Skip labeling blur/unidentifiable bees (as per your guideline).
* Save frequently.

---

### ✅ Result

You now have a Label Studio project with:

* Object detection task (bounding box)
* Single class: `"stingless_bee"`
* Images ready to annotate and export to YOLO
