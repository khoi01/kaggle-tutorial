# 🧭 Flask Learning Roadmap Checklist

---

## 🟢 Beginner Level – Python Essentials
- [ ] 1.Python syntax (variables, functions, loops, conditionals)
- [ ] 2.`dict`, `list`, `tuple`, `set` operations
- [ ] 3.File handling (`open`, `read`, `write`)
- [ ] 4.Exception handling (`try/except`)
- [ ] 5.Virtual environments (`python -m venv`)
- [ ] 6.Package management (`pip install`)
- [ ] 7.Python imports and module structure

---

## 🟡 Intermediate Level – Flask Core
- [ ] 8.`Flask(__name__)` and basic app setup
- [ ] 9.Routing with `@app.route`
- [ ] 10.Flask Blueprints (modular routing)
- [ ] 11.Handling `request`, `request.json`, and `request.files`
- [ ] 12.Returning JSON with `jsonify()`
- [ ] 13.Connecting PostgreSQL with SQLAlchemy
- [ ] 14.ORM models with relationships (foreign key)
- [ ] 15.Uploading and saving files to disk
- [ ] 16.Using `.env` with `python-dotenv`
- [ ] Dockerfile + Docker Compose setup

---

## 🔴 Advanced Level – Production Flask
- [ ] 17.App factory pattern (`create_app()`)
- [ ] 18.JWT Authentication (login → token → auth-protected route)
- [ ] 19.CORS configuration
- [ ] 20.Logging and error handling
- [ ] 21.Background tasks (e.g. for image processing)
- [ ] 22.Securing API endpoints
- [ ] 23.PostgreSQL on DigitalOcean (external connection)
- [ ] 24.Deploying Flask with Docker to DigitalOcean App Platform
- [ ] 25.API versioning (`/api/v1/...`)
- [ ] 26.Testing with `pytest` or `unittest`
