# 🧭 Flask Learning Roadmap Checklist

---

## 🟢 Beginner Level – Python Essentials
- [ ] Python syntax (variables, functions, loops, conditionals)
- [ ] `dict`, `list`, `tuple`, `set` operations
- [ ] File handling (`open`, `read`, `write`)
- [ ] Exception handling (`try/except`)
- [ ] Virtual environments (`python -m venv`)
- [ ] Package management (`pip install`)
- [ ] Python imports and module structure

---

## 🟡 Intermediate Level – Flask Core
- [ ] `Flask(__name__)` and basic app setup
- [ ] Routing with `@app.route`
- [ ] Flask Blueprints (modular routing)
- [ ] Handling `request`, `request.json`, and `request.files`
- [ ] Returning JSON with `jsonify()`
- [ ] Connecting PostgreSQL with SQLAlchemy
- [ ] ORM models with relationships (foreign key)
- [ ] Uploading and saving files to disk
- [ ] Using `.env` with `python-dotenv`
- [ ] Dockerfile + Docker Compose setup

---

## 🔴 Advanced Level – Production Flask
- [ ] App factory pattern (`create_app()`)
- [ ] JWT Authentication (login → token → auth-protected route)
- [ ] CORS configuration
- [ ] Logging and error handling
- [ ] Background tasks (e.g. for image processing)
- [ ] Securing API endpoints
- [ ] PostgreSQL on DigitalOcean (external connection)
- [ ] Deploying Flask with Docker to DigitalOcean App Platform
- [ ] API versioning (`/api/v1/...`)
- [ ] Testing with `pytest` or `unittest`

---
