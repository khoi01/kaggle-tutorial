## 🎯 Learning Path: YOLO Object Detection

---

### 🧩 **Module 11: YOLO Dataset Format Preparation**
- Convert CSV (ball labels) → YOLO TXT format

- Normalize bounding boxes (x_center, y_center, width, height)

---

### 🧩 **Module 12: Labeling Tools & Platforms**
- Use `labelImg`, `makesense.ai`, or `Roboflow` to annotate & export
- Optional: Convert from other formats (Pascal VOC → YOLO)

---

### 🧩 **Module 13: Train YOLOv5 / YOLOv8**
- Clone YOLO repo or use `pip install ultralytics`
- Setup `data.yaml` and config files
- Train on your custom dataset (ball)

---

### 🧩 **Module 14: Run Inference**
- Predict on new images
- Draw bounding boxes
- Count objects (e.g. bees or balls)

---

### 🧩 **Module 15: Export, Share, or Deploy**
- Save model `.pt` or `.onnx`
- Convert for Edge AI (Raspberry Pi, Jetson, etc.)
- Deploy via web/app
